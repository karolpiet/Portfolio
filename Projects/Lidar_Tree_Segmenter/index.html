LidarTreeSegmenter – Tree Detection and Forest Inventory from LiDAR Point Clouds

LidarTreeSegmenter is a Python tool I am developing to turn a terrestrial or mobile LiDAR scan of a forest plot (TLS, MLS, handheld SLAM) into tree-level inventory data. The idea is simple: drop a .laz / .las file onto the program and get, for every tree, its position, DBH, height and an estimate of timber volume, plus a plot-level summary.

The pipeline runs end to end. I first checked it on a synthetic plot where the true DBH and heights are known, and I am now running it on real scans of forest plots in Austria. The images and the 3D view on this page come from one of those real plots. The numbers are the tool's own output and have not yet been checked against field measurements.

How it works

  1. Pre-processing: noise removal, ground classification, terrain model and normalisation of point heights above ground.
  2. Stem detection: circles are fitted to bark points in thin horizontal slices; circles that stack into a near-vertical cylinder are accepted as stems.
  3. Segmentation: every point of the cloud is assigned to the nearest stem using a neighbourhood graph, so each tree gets its own ID.
  4. Tree parts: the stem is tracked upwards every 20 cm into the crown and points are split into stem, branches, foliage and understory.
  5. Quality checks: geometric tests to remove false trees (shrubs, stumps, snags) and to resolve DBH disagreements.
  6. Outputs: Excel report, GeoPackage with a QGIS project, per-tree images and an interactive 3D view in the browser.

No pre-trained machine-learning model or GPU is needed: the approach is mostly geometric (circle and cylinder fitting, neighbourhood graphs).

Status: this is an unfinished, experimental tool. Parts of the pipeline (especially species recognition from tree shape and volume estimation with generic form factors) are rough and need more work and proper validation against field measurements. Next steps: comparing results with field-measured trees, testing on more plots and improving accuracy in dense stands.

Technical Details

Platform & Tools

  • Python (NumPy, laspy, scikit-learn)
  • GeoPackage + QGIS project output
  • three.js for the 3D browser view
  • Simple Windows GUI with batch processing

Input Data

  • Terrestrial / mobile LiDAR (TLS, MLS, SLAM)
  • .las / .laz point clouds
  • Optional: scanner trajectory, GPS field measurements

Methods

  • Ground filtering and terrain model
  • Circle and cylinder fitting (DBH)
  • Graph-based point-to-tree segmentation
  • Stem / branches / foliage classification
