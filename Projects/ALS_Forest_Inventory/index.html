Forest Inventory from Airborne LiDAR – Wierzchowiska Pine Forest

Poland publishes airborne laser scanning (ALS) for the whole country through the national Geoportal. I took two ISOK sheets covering a pine forest near Wierzchowiska in east-central Poland (Masovian Voivodeship): 46.4 million points, about 17 points per m², flown in April 2014 and already classified into ground, vegetation and noise. From that raw point cloud I built a small forest inventory and turned it into a tool anyone can use from a browser.

Processing pipeline (Python)

  1. Raster models: digital terrain model (DTM) from ground points, surface model (DSM) from first returns and the canopy height model CHM = DSM − DTM, all at 0.5 m.
  2. Individual trees: tree tops are local maxima of the smoothed CHM with a search window that grows with tree height; crowns are delineated with marker-controlled watershed segmentation.
  3. Crown closure: for each crown, the share of first laser returns that stopped in the crown instead of reaching the ground. Open crowns mark stand edges, gaps and weaker trees.
  4. Timber volume: two independent estimates. A) sum over detected trees, with DBH from a height–diameter relation for pine and a stem form factor. B) area-based: canopy height (95th percentile) × closure × an assumed basal area of 28 m²/ha, in 20 × 20 m cells. The truth is usually between them.
  5. Web version: the models are packed into compact binary files (CHM at 0.5 m, 70,554 trees) and the parcel calculation was ported to JavaScript. It reproduces the Python tool to within 0.1% on five test areas.

What I deliberately did not do

An early version tried to split trees into "conifers" and "broadleaves" with a clustering algorithm. Clustering always returns as many groups as you ask for, and the official forest data show this stand is pure pine, so the "broadleaves" were an artefact. I removed the classification and show crown closure instead, which is a real, measured property.

Limits: the laser sees tree height, not stem diameter, so volumes are estimates with an uncertainty of roughly ±25% and they describe the forest as it was in April 2014. For a timber sale you need field measurements or the official stand description. Trees below the main canopy are mostly hidden, and touching crowns can merge into one tree.

Technical Details

Platform & Tools

  • Python (laspy, NumPy, SciPy, rasterio, scikit-image)
  • JavaScript: Leaflet, proj4js, three.js
  • QGIS for checking the results
  • Static site, no server: runs on GitHub Pages

Data Sources

  • ALS point clouds, ISOK 2014 (GUGiK)
  • Parcel boundaries: ULDK and KIEG services (GUGiK)
  • Orthophoto: Geoportal WMS
  • Stand descriptions: Forest Data Bank (BDL)

Methods

  • DTM / DSM / CHM rasterisation
  • Local-maximum tree detection, watershed crowns
  • Crown closure from first returns
  • Tree- and area-based volume models
